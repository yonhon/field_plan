# 速さの測定の記録

`node scripts/perf/run.mjs --record` の結果を、1 行ずつ足す。測り方と、レビューに進む目安は `docs/performance.md` にある。

- 値は、スマホ相当（CPU 1/4、幅 390 px、Chrome）で、7 回の中央値（起動は 5 回）。単位は ms。実機の値ではない。
- 起動: 開き直して画面が出るまで（端末に取っておいた中身を使う 2 回目以降）。
- タブ: 押してから次の描画まで。かっこの中は、そのあいだの配置の計算の回数。圃場図は、日程から戻ったとき。
- load_field: 起動の読み込み（`field.load_field`）が返す中身の大きさの見込み（KB、圧縮前）。DB が変わっていたときに受け取る量。
- 測るたびに 1〜2 割揺れる。PC が忙しいと 2 倍ほど揺れるので、前回と大きく違えば測り直す。

## 実機の起動

Android の Chrome のネットワークの記録（`docs/performance.md` の「実機の起動のログ」）から読んだ値。単位は秒。しばらく使っていなかったあとの最初の起動（ログインの更新と事前確認が要る）。

- 画面: アプリを開いてから、画面が出るまで（起動の読み込みの返事のすぐあと）。
- ログインの更新: 事前確認と本体を合わせた時間。
- 起動の読み込み: 画面が出るまでに待った DB の要求（事前確認を含む）。かっこの中は、要求の数（事前確認を含む）と、受け取った量。
