# 台帳

ロゴのメニューの「台帳…」で開きます。計画と記録が参照する登録の置き場です（今後、資材の単価や出荷先なども置く予定）。どれもすべての圃場とプランで共通です。

## サブタブ

「品目」「工程作業日数」「肥料」の 3 つのサブタブに分けます。

- **品目**: 品目ごとの設定値。
- **工程作業日数**: 作業の種類と目安の日数、次の作業までにあける日数。初期値は仮の値です。
- **肥料**: 肥料の銘柄。

- サブタブごとに URL を持ち、戻る・進むでサブタブを行き来できます。
- 最後に開いたサブタブを、ほかのタブから台帳に戻ったときと、次にアプリを開いたときに開きます（ブラウザーが覚えます）。
- 品目の表は横に送れるので、品目の名前の列を左に固定しています。
- スマホでは、どの表も見るだけです。

## 品目の設定値

| 設定値 | 使いみち |
|---|---|
| 畝幅、隙間 | 日程の「区画と畝」で品目を選んで畝を足すときの寸法。実際の畝幅と違うと「確認が必要な点」に出る |
| 条数、株間 | 苗数（定植・播種の実績に株間・条数を記録した作付は、実績の値で数える） |
| 窒素（kg/10a）、肥料 | 窒素量と、肥料の量 |
| マルチ | 作付に品目を選んだときの、ひな形の初期値（マルチあり、マルチなし） |
| 定植・播種から収穫開始まで（日）、収穫の日数 | ひな形や並べ直しで入る収穫の日付と、間隔の指摘。その品目の作付にだけ効く |
| 収量（kg/10a）、収量（g/株）、出荷率（%）、想定単価（円/kg・税抜き） | 作付ごとの収量と売上の見込み（[収支](revenue.md)の「収量と売上の見込み」）。作付ごとに違う値は、入力の窓の「収量と単価」のタブで、見直すたびに記録する |
| 市況での品目名 | 想定単価が空のとき、収穫の時期の市況から単価を推す |
| 条間、千鳥、品種、メモ | 記録用。計算には使わない |

- 空の欄は計算に使いません。名前だけの品目も登録できます。
- 品目の名前を変えると、作付の名前も変わります。品目を削除すると、作付には名前だけが残ります。

## 作付に品目を割り当てる

2 通りあります。

- **畝を足すときに決める**: 日程の「区画と畝」で、畝幅の左の欄から品目を選ぶと、畝幅と隙間が入ります。そのまま「右端に追加」か「＋」で足すと、その品目の作付と、ひな形の作業が付いた畝になります。
- **あとから決める**: 窓の工程の計画で畝を開き、「次の作付を追加」の品目を選んで「作付を追加」を押します。
  - すでにある作付は、作付ごとの品目の欄で選び直します。
  - 登録していない品目は、「登録していない品目」のまま名前を入れます。

## 苗数と施肥量

品目を割り当てた作付には、日程の「区画と畝」の畝の下に、苗数と肥料の量が出ます。

- 苗数は、定植・播種の実績に株間・条数を記録していればその値で、なければ品目の設定値で数えます。
- 区画ごとの合計は、日程の画面の「苗・肥料・収量の集計（この区画）」に出ます（[日程](schedule.md)の「区画の頭の欄」）。

### 式

収量と売上の式は、[収支](revenue.md)の「収量と売上の見込み」にあります。

| 項目 | 式 |
|---|---|
| 苗数 | 切り捨て（畝長 ÷ 株間）× 条数 |
| 畝の面積 | 畝長 × 畝幅 |
| 窒素量 | 畝の面積 × 10 a あたりの窒素量 ÷ 1,000 ㎡ |
| 肥料の量 | 窒素量 ÷ 肥料の窒素成分（%） |

### 1 穴あたりの量

作業の計画と実績の窓で、肥料と農薬の「1 穴あたり」に量を入れると、対象に選んだ畝の苗数（穴の数）を掛けた量になります。

- 記録の量は使った合計で、1 穴あたりの量も残ります。
- 苗数が分からない畝（品目を登録していない、株間か条数がない）を選んでいると、保存できません。
- 区画で選ぶときは使えません。
