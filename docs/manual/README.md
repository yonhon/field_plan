# 使い方

field_plan の画面の操作です。アプリの考え方は [README](../../README.md) にあります。
タブごとにファイルを分けています。どのタブにも属さない操作は「共通の操作」にあります。

| 文書 | 内容 |
|---|---|
| [共通の操作](common.md) | お知らせ、新しい版、圃場とプランの窓、元に戻す・やり直す、2 台で使うとき、ログアウト、PDF 出力 |
| [今日](today.md) | 「今日」のタブ。遅れている作業・今週やること・最近の実績・ニュースの欄、作業時間の計測 |
| [圃場図](map.md) | 「圃場図」のタブ。拡大・縮小、作図、圃場の設定の窓、下絵、耕起対象区画と畝、警告 |
| [日程](schedule.md) | 「日程」のタブ。区画と畝の図、工程表、作業を入力する窓、並べ直し、確認が必要な点、作付の詳細 |
| [日記](diary.md) | 「日記」のタブ。書く、読む、探す |
| [収支](revenue.md) | 「収支」のタブ。作業時間の集計、収量と売上の見込み |
| [台帳](ledger.md) | メニューの「台帳…」。品目、工程作業日数、肥料、苗数と施肥量の式 |
| [変更の履歴](history.md) | メニューの「変更の履歴…」。計画の変更の記録、アプリの更新 |

## 画面の移り方

上のタブは、今日、圃場図、日程、日記、収支の 5 つです。台帳と変更の履歴は毎日は開かないので、ロゴのメニューの「台帳…」「変更の履歴…」で開きます。

### URL

どの画面も、作付の詳細も、それぞれ URL を持ちます。

| 画面 | URL |
|---|---|
| 今日、圃場図、日記、収支、変更の履歴 | `#today`、`#map`、`#diary`、`#revenue`、`#journal` |
| 日程（開いている区画を付ける） | `#schedule/block/区画の ID` |
| 台帳（開いているサブタブを付ける） | `#master/crops`、`#master/work-days`、`#master/fertilizers` |
| 作付の詳細 | `#detail/planting/作付の ID` |

- 前の URL も開けます。品目の画面の `#crops` は台帳の品目を、区画の詳細の `#detail/block/区画の ID` は日程の画面のその区画を開きます。
- 画面を移るたびにブラウザーの履歴に積むので、戻る・進むで前の画面に戻れます。再読み込みやブックマークでも、同じ画面を開きます。
- 作付の詳細で隣の作付へ移るときは、履歴を積みません。何本か見てからでも、戻る 1 回で日程に戻ります。

### 最後に見ていた画面

- **アプリを開いたとき**: URL に画面が書かれていなければ、最後に開いていた上のタブを開きます。覚えていなければ圃場図です。覚えるのはブラウザーで、端末ごとです。メニューから開く台帳と変更の履歴は覚えません。
- **日程のタブ**: 最後に見ていた画面に戻ります。作付の詳細を見ていたならその作付の詳細を、日程の画面を見ていたならその区画と畝を開きます。アプリを開き直したときも同じです（ブラウザーが圃場ごとに覚えます。区画と畝はプランごと）。
- 作付の詳細を見ているときに日程のタブを押すと、日程の画面に移り、その作付の畝を選びます。

## ヘッダー

- **圃場とプランの名前**: 左上のロゴの横に、開いている圃場の名前と、その下にプランの名前を出します（圃場を開く前は「圃場計画」）。
- **長い名前**: 名前の欄は、ヘッダーが 1 段に収まる空きまで広げます。収まらない名前は、末尾を「…」で省きます。省いても入らない幅では、ヘッダーを 2 段に折り返します。
- **実際に使うプランでないとき**: プランの名前を赤い太字にして「⚠」を付けます。

### メニュー

ロゴと名前を押すと開きます。上から次の順に並びます。

1. 開いている圃場とプラン（省かずに出す）
2. スマホだけ: 「元に戻す」（↶）「やり直す」（↷）と押しピン（[共通の操作](common.md)の「元に戻す、やり直す」）
3. 「圃場とプランを選ぶ…」
4. 「圃場の設定…」（PC だけ）
5. 「台帳…」、「変更の履歴…」
6. ログインしているアカウント（メールアドレス）とログアウト

- 閉じるときは、メニューの外を押すか、Esc を押すか、ロゴと名前をもう一度押します。
- ログアウトするとき、日記の書きかけがこの端末に残っていれば、消してよいかを確かめてから消します（日記にはほかの方の名前も入るため）。
