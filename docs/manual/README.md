# 使い方

field_plan の画面の操作です。アプリの考え方は [README](../../README.md) にあります。

| 文書 | 内容 |
|---|---|
| [共通の操作](common.md) | 圃場とプランの窓、元に戻す・やり直す、2 台で使うとき、ログアウト、PDF 出力 |
| [今日](today.md) | 「今日」のタブ。作業時間の計測 |
| [圃場図](map.md) | 「圃場図」のタブ。作図、圃場の設定の窓、下絵、耕起対象区画と畝 |
| [日程](schedule.md) | 「日程」のタブ。工程表、区画と畝の図、作業を入力する窓、並べ直し、確認が必要な点 |
| [日記](diary.md) | 「日記」のタブ |
| [収支](revenue.md) | 「収支」のタブ。作業時間の集計、収量と売上の見込み |
| [台帳](ledger.md) | メニューの「台帳…」。品目、工程作業日数、肥料、計算式 |
| [変更の履歴](history.md) | メニューの「変更の履歴…」。アプリの更新 |

## 画面の移り方

上のタブは、今日、圃場図、日程、日記、収支の 5 つです。台帳と変更の履歴は、ロゴのメニューの「台帳…」「変更の履歴…」で開きます（毎日は開かない画面なので、タブから外しました）。
どの画面も、作付の詳細も、それぞれ URL を持ちます（`#today`、`#map`、`#diary`、`#revenue`、`#journal`、日程は開いている区画を付けて `#schedule/block/区画の ID`、台帳は開いているサブタブを付けて `#master/crops`・`#master/work-days`・`#master/fertilizers`、作付の詳細は `#detail/planting/作付の ID`）。前の品目の画面の URL（`#crops`）は、台帳の品目を開きます。前にあった区画の詳細の URL（`#detail/block/区画の ID`）は、日程の画面でその区画を開きます。画面を移るたびにブラウザーの履歴に積むので、戻る・進むのボタンで前の画面に戻れます。再読み込みやブックマークでも、同じ画面を開きます。作付の詳細で隣の作付へ移るときは履歴を積まないので、何本か見てからでも、戻る 1 回で日程に戻ります。

日程のタブは、最後に見ていた画面に戻ります。ほかのタブに移ってから日程のタブを押すと、作付の詳細を見ていたならその作付の詳細を、日程の画面を見ていたならその区画と畝を開きます。アプリを開き直したときも同じです（ブラウザーが圃場ごとに覚えます。区画と畝はプランごと）。作付の詳細で日程のタブを押すと、日程の画面に移り、その作付の畝を選びます。

URL を開いたときに URL に画面が書かれていなければ、最後に開いていた上のタブ（今日、圃場図、日程、日記、収支）を開きます。覚えていなければ圃場図です。ブラウザーが端末ごとに覚えます。メニューから開く台帳と変更の履歴は覚えません。日程を覚えていたときは、日程のタブを押したときと同じく、最後に見ていた日程の画面か作付の詳細を開きます。圃場図の上には、警告の欄を出します。「今日」のタブには、［遅れている作業｜今週やること｜最近の実績｜ニュース］のタブの欄を出します。タブの欄は、初めは「今週やること」を開きます。遅れている作業があるときは、そのタブの名前に ⚠ と件数を付けます。ニュースのタブには、県のページに載った新しい記事（リンクの文をそのまま）を未読として出し、未読があればタブの名前に ⚠ と件数を付けます。行の右端の「確認」を押すと既読へ移り、「既読を見る」で既読の一覧（確認した新しい順に 30 件）に切り替わります。既読から「未読に戻す」もできます。PC では欄の高さを 150〜420px にしていて、はみ出す分は欄の中で送ります。スマホでは中身に合わせた高さです。

ヘッダーの左上には、ロゴの横に、開いている圃場の名前と、その下にプランの名前を出します（圃場を開く前は「圃場計画」）。名前の欄は、ヘッダーが 1 段に収まる空きまで広げ、収まらない名前は末尾を「…」で省きます。省いても入らない幅では、ヘッダーを 2 段に折り返します。実際に使うプランでないプランを開いているときは、プランの名前を赤い太字にして「⚠」を付けます。

ロゴと名前を押すと、メニューが開きます。上から、開いている圃場とプラン（省かずに出す）、スマホだけの「元に戻す」（↶）「やり直す」（↷）と押しピン（[共通の操作](common.md)の「元に戻す、やり直す」）、「圃場とプランを選ぶ…」、「圃場の設定…」（PC だけ）、「台帳…」、「変更の履歴…」、ログインしているアカウント（メールアドレス）とログアウトです。閉じるときは、メニューの外を押すか、Esc を押すか、ロゴと名前をもう一度押します。ログアウトするとき、日記の書きかけがこの端末に残っていれば、消してよいかを確かめてから消します（日記にはほかの方の名前も入るため）。
