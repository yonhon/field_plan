# 画面のデザインのきまり

画面を作るとき、直すときに守るきまりです。色の値は `app/styles.css` の `:root` にまとめてあり、きまりの多くはそこと、すぐ下の土台の指定（`a` など）で効かせています。

## 色

| 名前 | 値 | 使うところ |
|---|---|---|
| `--accent` | #0b6b72 | アプリの色。リンク、主なボタン、選んでいるものの印 |
| `--text` | #13262a | ふつうの文字 |
| `--muted` | #56696c | 添え書き、説明の文 |
| `--memo` | #3d5154 | 計画と実績の中身（メモ、資材、仕様） |
| `--danger` | #ce4d41 | 消す、取りやめる、誤り、今日の線 |
| `--line` | #c8d8d7 | 枠と区切りの線 |
| `--bg` / `--surface` | #f7f6f1 / #ffffff | 画面の地と、欄（パネル）の地 |

## メモの文字（暫定）

- **作付の詳細の表で、計画と実績の中身（メモ、資材、仕様）は、12px・`--memo` の色で出す。** `app/styles.css` の `.detail-line` を付ける。計画の側と実績の側で、同じ見た目にそろえるため。
- **メモを入力する欄は、日程の作業の表のメモと同じ 13px・`--text` にする。** 「計画を直す」の窓（`.plan-edit textarea`）と、入力の窓（`.log-body textarea`）のメモ欄。表示（12px・`--memo`）と入力で大きさが違うのは、書きやすさを優先したため。
- 入力欄（`textarea`）は、指定しないとブラウザーの初めの等幅の書体になるので、`font-family: inherit` を必ず付ける。
- スマホの幅（800px 以下）では、入力欄を 16px にする。これより小さいと、iPhone で入力のたびに画面が拡大される。
- 変更の記録の日ごとのメモ（13px）と日記の本文（15px）は、文章を書く欄なので、このきまりの外。
- 説明文や単位などの添え書き（`.muted`、13px・`--muted`）とは分ける。
- 暫定のきまり。ほかの画面のメモ（日程の作業の一覧など）にも広げるかは、あとで決める。

## 農薬名

- **農薬名を出すところでは、名前の後ろに必ず作用機構分類（RAC コード）のアイコンを付ける。** `app/pesticide.js` の `nameHtml`（実績の資材の行は `inputHtml`）を通して出す。名前を `escapeHtml` だけで出さない。`tests/rac.test.mjs` が確かめる。
- 文字しか出せない所（確認の窓など）は、`nameText` で「（IRAC 4A）」と書き添える。
- 形と色は `app/rac.js` にまとめてある（`docs/actuals-plan.md` の 4.9）。

## リンク

- **下線は付けない。**
- **文字の色は、アプリのデザインに合わせる。ブラウザーの初めの色（青い文字、押したあとの紫）は使わない。**
  - 何も指定しなければ、アプリの色（#0b6b72、`--accent`）になる。作付の詳細の日付、FAMIC の注意事項などがこれ。
  - まわりの文字と同じ色にしたほうが読みやすい所は、まわりと同じ色にしてよい。工程表の区画の名前・畝の番号・品目の名前は、名前の一覧として読むので、まわりと同じ色にしている。
- 一度押したリンクも、色を変えない。指したときも、色や下線を変えない。
- `app/styles.css` の土台の `a` の指定（色は `--accent`、下線なし）で効かせているので、新しいリンクに個別の指定は要らない。まわりと同じ色にするときだけ、`color: inherit` を付ける。ブラウザーの初めの見た目（青い文字に下線）が出ていたら、きまりから外れている。

## 選ぶものと操作

- **いくつかの中から 1 つを選ぶスイッチは、ボタンをつなげた 1 つの枠にする。** 入れ物に `app/styles.css` の `.seg` を付け、中に `.chip-btn`（選んでいるものに `is-on`）か `.mode-btn`（`is-active`）を並べる。工程表の表示と表示期間、作付の詳細の表示、日記の 日／月 と 新しい順／古い順、入力の窓の 計画／実績 と 品目で選ぶ／区画で選ぶ、圃場図の道具がこれ。
- **押すと何かが起きるボタン（PDF出力、コピー、修正など）は、離れたチップ（`.chip-btn`）のままにする。** つながった形と離れた形で、選ぶものと操作を見分ける。
- 選んでいるものは `--accent` で塗る。太字にはしない（押しても幅が変わらないように）。画面の切り替え（上部のタブ）と同じ形で、大きさはチップと同じ 13px にとどめ、画面の切り替えより一段軽く見せる。
- 組の中では折り返さない。幅が足りないときは、組ごとに次の行へ送る。
- 圃場図の道具は、全体で 1 つだけ選べる（`state.mode`）。組（選択・移動／外形／区域／耕起対象区画）ごとにつなげるので、選んでいない組は、どれも塗られていない。使い終えると「選択・移動」に戻る。
- 複数選べるもの（入力の窓の畝や中身、日記のタグ）と、選択肢が多いもの（入力の窓の作業の種類）は、折り返せる離れたチップのままにする。

## お知らせ

保存や操作の結果は、ヘッダーの下に重ねて出すお知らせ（`app/toast.js`）で知らせる。ヘッダーや画面の形は変えない。文は `setStatus` で保存の状態の欄に書く（`AGENTS.md` の「Reporting failures」）。

- **操作の結果**（実績を入力しました、など）: 2 秒で消す。
- **保存**: 「保存しました」は出さない。保存に 1 秒以上かかるときだけ「保存中…」を出す。
- **進み具合**（画像を保存中… 45% など）: 終わるまで出しておく。
- **失敗**（保存に失敗しました、日記を読み込めませんでした、など）: 自然には消さない。「詳しく」で誤りの内容を窓に出し、「×」で閉じる。保存の失敗は、あわせて窓でも知らせる。
- **保存の送り直し**: 図形の自動保存に失敗したときは、5 秒、15 秒、60 秒たったときと、回線が戻ったとき、次に保存するときに、もう一度送る。送り直しの失敗は、窓では知らせない（お知らせは残す）。
- **新しい版**: 新しい版は画面が出たあとで取り、「アプリの新しい版があります」と「読み込み直す」を出す。

## 今日のタブの計測のボタン

圃場ではスマホで今日のタブを開き、作業を始める・止める・完了を押すことが最も多い。指で押しやすくしつつ、ほかの画面と見た目をそろえる（2026-11-25 に本人と決めた。スマホは案B2、PC は PC4）。

- **スマホの幅（800px 以下）では、計測に使うボタン（作業を始める、休憩、止める、再開、今週やることの始める・完了・止める）を、高さ 44px 以上にする。** PC はマウスで押すので、ほかの画面と同じ大きさ（チップ）のままにする。
- **作業を始めるボタン（観察、準備・片付け、移動、計画にない作業…）には、名前の前に絵を付ける。** PC は離れたチップと同じ丸い形で、絵を左に置く。スマホは 4 つを 1 行に並べたタイル（絵の下に名前）にする。測っている種類のボタンは、アプリの色で塗り、経過した時間と「止める」にする（押すと止まる）。
- 絵は `app/icons.js` の決まり（24 × 24、線の太さ 1.7、線の端は四角）で描く。移動は道のり（出発の点から目的地の印までの点線の山）、計画にない作業はスコップ。矢印（ブラウザーの操作でよく見る）と ＋（「＋ 入力する」で使っている）は使わない。
- **スマホの今日のタブでは、計測中の帯の代わりに、始めるボタンの上に計測の枠を出す。** 測っていないとき（「計測していません」）と休憩中も同じ高さで出したままにして、下の欄が上下に動かないようにする。名前ははみ出す分を … で切り、1 行にとどめる。ほかのタブでは帯を出す。
- **今週やること・遅れている作業の行は、スマホでは、右に丸いボタン（直径 48px。下に小さく名前）を置く。** 始めるは枠だけ、完了は塗り、測っている行の止めるは `--danger` の枠。測っている行は薄い色で塗る。修正は、場所の後ろの文字のボタンにする。PC は今のチップのまま。
- **計画にない作業の種類は、管理作業と工程の作業に分けて並べる。** PC は折り返すチップ。スマホは画面の下から出る欄にして、大きさのそろったボタン（高さ 48px）を 3 列に並べる。選択肢が多いものを折り返すチップにするきまりの、スマホだけの例外（指で押すため）。
- 遅れている作業・今週やること・最近の実績・ニュースのタブは、スマホでは折り返さずに 1 行に並べ、はみ出た分は横に送る（スクロールバーは出さない）。
