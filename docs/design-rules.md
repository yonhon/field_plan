# 画面のデザインのきまり

画面を作るとき、直すときに守るきまりです。色の値は `app/styles.css` の `:root` にまとめてあり、きまりの多くはそこと、すぐ下の土台の指定（`a` など）で効かせています。

## 色

| 名前 | 値 | 使うところ |
|---|---|---|
| `--accent` | #0b6b72 | アプリの色。リンク、主なボタン、選んでいるものの印 |
| `--text` | #13262a | ふつうの文字 |
| `--muted` | #56696c | 添え書き、説明の文 |
| `--memo` | #3d5154 | 計画と実績の中身（メモ、資材、仕様） |
| `--danger` | #ce4d41 | 消す、取りやめる、誤り、今日の線 |
| `--line` | #c8d8d7 | 枠と区切りの線 |
| `--bg` / `--surface` | #f7f6f1 / #ffffff | 画面の地と、欄（パネル）の地 |

## メモの文字（暫定）

- **作付の詳細の表で、計画と実績の中身（メモ、資材、仕様）は、12px・`--memo` の色で出す。** `app/styles.css` の `.detail-line` を付ける。計画の側と実績の側で、同じ見た目にそろえるため。
- **メモを入力する欄は、日程の作業の表のメモと同じ 13px・`--text` にする。** 「計画を直す」の窓（`.plan-edit textarea`）と、入力の窓（`.log-body textarea`）のメモ欄。表示（12px・`--memo`）と入力で大きさが違うのは、書きやすさを優先したため。
- 入力欄（`textarea`）は、指定しないとブラウザーの初めの等幅の書体になるので、`font-family: inherit` を必ず付ける。
- スマホの幅（800px 以下）では、入力欄を 16px にする。これより小さいと、iPhone で入力のたびに画面が拡大される。
- 変更の記録の日ごとのメモ（13px）と日記の本文（15px）は、文章を書く欄なので、このきまりの外。
- 説明文や単位などの添え書き（`.muted`、13px・`--muted`）とは分ける。
- 暫定のきまり。ほかの画面のメモ（日程の作業の一覧など）にも広げるかは、あとで決める。

## 農薬名

- **農薬名を出すところでは、名前の後ろに必ず作用機構分類（RAC コード）のアイコンを付ける。** `app/pesticide.js` の `nameHtml`（実績の資材の行は `inputHtml`）を通して出す。名前を `escapeHtml` だけで出さない。`tests/rac.test.mjs` が確かめる。
- 文字しか出せない所（確認の窓など）は、`nameText` で「（IRAC 4A）」と書き添える。
- 形と色は `app/rac.js` にまとめてある（`docs/actuals-plan.md` の 4.9）。

## リンク

- **下線は付けない。**
- **文字の色は、アプリのデザインに合わせる。ブラウザーの初めの色（青い文字、押したあとの紫）は使わない。**
  - 何も指定しなければ、アプリの色（#0b6b72、`--accent`）になる。作付の詳細の日付、FAMIC の注意事項などがこれ。
  - まわりの文字と同じ色にしたほうが読みやすい所は、まわりと同じ色にしてよい。工程表の区画の名前・畝の番号・品目の名前は、名前の一覧として読むので、まわりと同じ色にしている。
- 一度押したリンクも、色を変えない。指したときも、色や下線を変えない。
- `app/styles.css` の土台の `a` の指定（色は `--accent`、下線なし）で効かせているので、新しいリンクに個別の指定は要らない。まわりと同じ色にするときだけ、`color: inherit` を付ける。ブラウザーの初めの見た目（青い文字に下線）が出ていたら、きまりから外れている。
